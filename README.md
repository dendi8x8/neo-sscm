For installing on GNU\Linux:
  For void linux:
  1) Install dependencies in dependencies.txt:
    xbps-install -S libX11 libX11-devel libXrandr-devel libXcursor-devel \
    libXinerama-devel libXi-devel libglvnd-devel
  2) Clone repository and cd:
    git clone https://github.com/dendi8x8/neo-sscm.git
    cd neo-sscm
  3) Run make, it will compile raylib for your platform.
